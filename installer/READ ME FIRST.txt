===============================================================================
  TallyPrime for Claude
  Ask Claude questions about your Tally books, in plain English.
===============================================================================

  This lets Claude read your TallyPrime data so you can ask things like:

     "What is my cash balance?"
     "Who owes me money, oldest first?"
     "Show me last month's sales"
     "What did I spend with Google this year?"

  It can only READ your books. It cannot create, change or delete anything in
  TallyPrime. There is no way for it to alter your accounts.


-------------------------------------------------------------------------------
  BEFORE YOU START
-------------------------------------------------------------------------------

  Three things need to be true. All of them are one-time, except the last.

  1. Claude Desktop OR Codex is installed on this computer.

     Either one works. Setup will ask which you use, and you can pick both.

  2. TallyPrime's connection setting is switched on. It is OFF by default.

        a. Open TallyPrime.
        b. From the Gateway of Tally, press  F1  and choose  Settings.
        c. Choose  Connectivity.
        d. Choose  Client/Server configuration.
        e. Set  TallyPrime acts as  to  Both  (or  Server ).
        f. Check that  Port  is  9000.
        g. Press  Ctrl+A  to save.

     You only do this once on this computer.

  3. TallyPrime is OPEN, with your company loaded, whenever you want to ask
     a question.

     This one is not optional and cannot be worked around. Tally only answers
     while it is running, and it serves one company at a time -- whichever one
     you have open. If you want to ask about a different company, open that
     company in Tally first.


-------------------------------------------------------------------------------
  HOW TO INSTALL
-------------------------------------------------------------------------------

  1. Put this folder somewhere it can stay. Your Documents folder is fine.
     Do not run it from inside the zip file.

  2. Double-click  Setup

     It asks three things.

        - Do you want the daily spreadsheet? (See the section below. If you
          say yes, a folder picker opens so you can choose where it goes --
          just click through to the folder, no typing -- and then it asks
          which companies to cover.)
        - Do you want the live Tally connector switched on as well?
        - Which app do you use -- Claude Desktop, Codex, or both?

     If you are not sure, just press Enter at each one.

     It then tells you what it did, and whether it could see your Tally.

  3. Close that app completely, then open it again.

     Closing the window is NOT enough. Claude Desktop keeps running in the
     notification area, next to the clock -- right-click its icon there and
     choose Quit, then start it again. Codex must also be fully closed and
     reopened, because it only reads its settings when it starts.

  4. Ask it:  "What is my cash balance in Tally?"

  That is it.


-------------------------------------------------------------------------------
  THE DAILY SPREADSHEET
-------------------------------------------------------------------------------

  Setup can keep an Excel workbook of your books up to date automatically --
  one file per company, a tab for each part of the books.

  Put that folder inside Google Drive and two useful things follow:

     - Claude can answer questions WITHOUT TallyPrime being open, because it
       reads the spreadsheet instead of your books.

     - You have an actual spreadsheet, which you can open, filter and send to
       somebody, rather than figures retyped out of a chat.

  It runs quietly in the background. Once an hour it asks Tally one very
  small question -- has anything changed? -- and stops there. It only writes
  a new spreadsheet when your books have actually moved, plus once a day so
  the file never looks newer than it is.

  TWO THINGS TO KNOW BEFORE YOU RELY ON IT

     Read the Manifest tab first. It says which company these figures are,
     what currency, what period, and -- this one matters -- WHEN they were
     last read from Tally. An answer from the spreadsheet is as at that
     moment, not as at now.

     Do NOT use  File > Save as Google Sheets  on it. That makes a separate
     copy that stops updating, while still looking live. Just open the file;
     Google Sheets reads it as it is, tabs and all.

  IF A FIGURE IS GOING INTO AN AUDIT FILE, check it against Tally directly
  first. The spreadsheet is for answering questions quickly, not for evidence.

  YOU WILL NOT SEE IT RUNNING. It works in the background with no window,
  so nothing pops up while you are working.

  TO EXPORT RIGHT NOW, without waiting: double-click  Run-Export
  (this one DOES show a window, so you can watch it)

  TO CHANGE WHERE IT SAVES: double-click  Setup  again. It shows you the
  folder it is using now and asks whether to keep it, so you can change just
  that one thing.

     It then offers to MOVE the old spreadsheets across, so you do not end
     up with two copies of one client's books and no way to tell which is
     current. Say yes and it copies them over, checks they arrived, and only
     then removes the old ones.

     It only ever moves the files IT created. If that folder also holds your
     own files, they are left exactly where they are.

     One warning it will also give you: if the old folder is inside Google
     Drive, removing files from it removes them from Drive too -- for
     everyone it is shared with. Say no if you would rather tidy up by hand,
     and it will just leave a note in the old folder instead.

  IF IT STOPS WORKING, you will see it in the folder -- a file whose NAME
  says what went wrong, like

     LAST RUN FAILED - the workbook is open in Excel - 2026-08-19 1805.txt

  The two usual causes are that TallyPrime was closed, or that you have the
  spreadsheet open in Excel so it cannot be replaced. Close it and the next
  run sorts itself out. Check-Tally also reports how old the spreadsheet is.


-------------------------------------------------------------------------------
  IF SOMETHING IS NOT WORKING
-------------------------------------------------------------------------------

  Double-click  Check-Tally

  It checks everything and tells you, in plain language, what to fix. It reads
  only; it changes nothing.

  The two most common problems:

     "Claude cannot see my Tally"
        TallyPrime is closed, or step 2 above was never done.
        Run Check-Tally -- it will tell you which.

     "It worked yesterday, not today"
        Usually TallyPrime is not open yet, or no company is loaded.


-------------------------------------------------------------------------------
  IF YOU MOVE THIS FOLDER
-------------------------------------------------------------------------------

  Double-click  Setup  again. That is the whole fix.

  Claude remembers where this folder was. Moving or renaming it breaks the
  link, and running Setup again repairs it.


-------------------------------------------------------------------------------
  INSTALLING A NEWER VERSION
-------------------------------------------------------------------------------

  1. Close Claude Desktop completely -- including its icon by the clock.
     This matters. If Claude is still running, some files cannot be replaced
     and you will end up with a half-updated folder.

  2. Unzip the new version.

  3. Double-click  Setup

  4. Open Claude Desktop again.

  To check which version you have: double-click Check-Tally, or just ask
  Claude "what version of the Tally connection are you using?"


-------------------------------------------------------------------------------
  REMOVING IT
-------------------------------------------------------------------------------

  Delete this folder. Nothing was installed anywhere else on your computer.

  Claude Desktop will still have an entry pointing at the folder you deleted;
  it will simply stop working, and can be left alone or removed by whoever set
  this up for you.


-------------------------------------------------------------------------------
  A NOTE ON YOUR DATA
-------------------------------------------------------------------------------

  This program talks to TallyPrime on this computer only, over your own
  machine's internal connection. It does not send your books anywhere by
  itself.

  Claude Desktop does send the specific figures you ask about to Claude, in
  order to answer your question -- the same as if you had typed them in. If
  that matters for a particular client, ask about that client's data only when
  you mean to.

  THE DAILY SPREADSHEET IS DIFFERENT, and you should be clear about it.

  If you set it up and choose a folder inside Google Drive, then your clients'
  accounting data is in Google Drive. This program does not upload anything --
  it writes an ordinary file to an ordinary folder on this computer, and your
  own Google Drive program is what copies it to the cloud, exactly as it would
  with any other file you put there.

  That is the whole point of the folder, and it is worth deciding on purpose
  rather than discovering later. If you would rather it stayed on this
  computer, choose a folder that Google Drive does not sync -- everything else
  works the same.
